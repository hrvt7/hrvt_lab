# Bar — checkable mechanisms
1. One accent only: yellow #f8dd4a on near-black; no second accent outside the three work panels.
2. Every heading has exactly one accent word, set visibly wider than the rest.
3. The main CTA (yellow pill) is visible on the first screen at 1440x900 and 390x844 without scrolling.
4. Each section uses a different timeline metaphor (layers, screenshot coming alive, clips, curve with keyframes, render queue, clips to scale, markers); no two sections share the same layout pattern; no generic card grid or stock accordion.
5. Selected work: the video frame is the largest element on screen and fully visible (not cut by nav or bottom bar) at 1440x900.
6. Text never overlaps other text or UI; nothing is clipped by the fixed nav or the bottom bar when at rest.
7. Body/secondary text readable: >= 16px body, labels >= 10px, contrast >= 4.5:1.
8. Empty space is intentional: no dead screen (a full viewport with < 2 content elements) between sections.
