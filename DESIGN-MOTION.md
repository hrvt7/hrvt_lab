# Design system — HRVT SaaS Motion Design
- Colours: base ink #0c0c0f; panels #131317 / #1c1c22 / #27272f; text paper #f1efe9; secondary text #a5a3af; ONE accent: HRVT yellow #f8dd4a (logo kit). Hairlines rgba(241,239,233,.10/.20). Work panels are the only exception: each takes its video's own palette (Orlo lilac #efe8ff, Mirra black #0a0a0a + lime, Halden cream #f1ede4 + orange).
- Type: display "Anybody Variable" (width axis; headings wdth ~92, the accent word wider ~132, weight 800); body "Geist"; labels/timecodes "Martian Mono" uppercase, 0.62–0.72rem.
- Scale: h1 clamp(2.25rem,4.3vw,4.5rem); h2 clamp(2rem,4.4vw,4.2rem); body 1–1.2rem, line-height 1.5–1.6; secondary text never below 4.5:1 contrast.
- Shape: pills for buttons (min height 52px, tap targets >= 44px); panels radius 12–18px; video frames 22px (14px mobile).
- Motion: headings open word by word from condensed to full width; scroll-driven effects per section; hover/focus/active on every clickable; focus ring 2px yellow.
- Layout: side margin clamp(18px,3.4vw,56px); fixed top pill nav; fixed bottom "page timeline" bar with WhatsApp + call CTA.
- Mobile (<=820px): single column, its own layouts (vertical step rail, FAQ markers as M1–M5 chips, CTA bar full width).
